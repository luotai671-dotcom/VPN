翻墙怪隐私政策与数据安全声明

翻墙怪 (FANQIANGGUAI · VPN INSIGHT) 高度重视访问者的数字隐私与数据主权。本隐私政策详细阐明我们在站点架构、本地交互以及外部服务对接中严格恪守的零追踪准则。

0 数据库 纯静态无痕架构 不存储任何访客身份日志
0 追踪器 拒绝商业采集脚本 绝不接入跨站广告追踪代码
本地计算 Ctrl+K 内存搜索 检索关键词 100% 留在本机
TLS 1.3 现代全站加密传输 端到端加密防护嗅探劫持

一、 核心原则：彻底的无日志与纯静态架构

翻墙怪全站采用纯静态 HTML / CSS / 原生 JavaScript 架构构建。我们从根本上杜绝了对用户隐私数据的依赖与收集：

  • 无用户数据库：本站不设任何用户注册、登录、会员系统，不需要读者绑定手机号、身份证号或社交账号；
  • 不记录访问日志：服务器不开启针对访客真实 IP 地址、操作系统指纹或具体页面停留时长的侵入式分析记录；
  • 无跨站画像追踪：绝不植入 Google Tag Manager、Meta Pixel、巨量引擎等任何商业数据追踪或跨站用户画像 Cookie。

二、 本地交互功能的数据安全保障

🔍 全站即时搜索功能（100% 本地浏览器运行）

站内提供的快捷搜索（⌘ K / Ctrl+K）采用预载本地 JSON 索引机制。当你输入关键词（如“闪电鼠”、“IEPL”、“Netflix”）时，匹配计算完全在你的本地浏览器内存中完成，没有任何检索请求会上传至外部服务器。

✉️ 订阅更新表单安全性说明

页面底部的“订阅更新”模块当前仅为前端交互架构展示（Mock Demonstration）。你在输入框内输入的任何邮箱地址均不会被持久化存储至任何远程数据库，亦不会被向外发送或泄露给任何营销机构。

三、 外部链接与第三方服务商隐私独立性

翻墙怪提供针对优质专线机场、VPN 官方网站、客户端开源项目（如 Clash Verge Rev、Shadowrocket、Sing-box）以及安全测试工具的直接跳转链接：

  • 自主隐私权属：当你点击外部链接跳转至各第三方服务商官方网站后，翻墙怪的隐私条款将不再适用。第三方平台拥有独立的用户隐私协议与数据处理政策；
  • 读者安全建议：在第三方服务商后台注册与订购时，建议读者遵循“最小信息原则”——使用专属小号邮箱（如 ProtonMail、DuckDuckGo 隐私邮箱）、选用加密虚拟币或受保护的支付方式，并妥善保管你的个人订阅链接（Subscription URL），切勿向公众泄露你的节点密钥。

四、 读者对数据安全的掌控权利

作为访问者，你对自己在互联网上的数据享有完全的主动权：

你可以随时通过浏览器的“清除浏览数据”选项，彻底删除本地缓存与 LocalStorage；你可以自由使用各类隐私保护浏览器扩展（如 uBlock Origin、Privacy Badger）浏览本站，翻墙怪全站功能均保证无损兼容运行。
